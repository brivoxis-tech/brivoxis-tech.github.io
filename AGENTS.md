# AGENTS.md — Brivoxis Tech Ltd (`brivoxis-tech.github.io`)

Guidelines for AI agents working in this repository.

## 1. Repository Purpose
Official static website for **BRIVOXIS TECH LTD** (`https://brivoxis-tech.github.io`), serving as:
- The company introduction, app portfolio showcase, and corporate verification portal.
- Individual app landing pages and privacy policies (hosted under `/apps/<slug>/`).

## 2. Git Commit Rules
- **Commit each sizable unit of work** with clear, concise commit messages.
- **Do NOT mention any AI agent name, model name, or AI attribution** (no `Co-authored-by`, no "Generated by...", etc.) in commit messages, PRs, or code comments.

## 3. SEO & Markup Standards
- Semantic HTML5 landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- One `<h1>` per page followed by logical `<h2>` and `<h3>` hierarchy.
- Unique `<title>`, `<meta name="description">`, `<link rel="canonical">`, Open Graph, Twitter Card, and JSON-LD structured data.
- Keep `.nojekyll` in the root for clean GitHub Pages serving.
